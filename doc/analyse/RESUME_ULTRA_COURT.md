**Plateforme B2C + B2B** qui connecte :
- 👤 **PROPRIÉTAIRES** (Canadiens) → Veulent des devis gratuits de pros vérifiés
- 👷 **PROFESSIONNELS** (Plombiers, électriciens, etc.) → Veulent des leads qualifiés

**Valeur clé** : Confiance + Transparence + Vérification rigoureuse

## 💡 NOTES IMPORTANTES

2. **Conversion focus** : Chaque section doit avoir une action (devis, inscription)
3. **Trust first** : Insistez sur vérification, transparence, avis
4. **Mobile first** : Concevez pour mobile d'abord
5. **SEO** : Ajoutez title, meta description, schema markup
